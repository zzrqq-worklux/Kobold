只留标签本身

不要常驻底框。标签的点击热区靠透明 padding；active 只靠文字/图标颜色 + 一个小三角或下划线。2–3 个组件时，这样最干净，也不会把 header 切成一格一格。

active 指示可以很小

不靠底框也能看清当前标签。下面是三种最轻的 active 指示，选一种即可，不建议同时叠太多。

点击热区

透明 padding 撑到 28–34px 高，视觉上仍然只有文字；不画底框也能点。

hover / focus

hover 只提亮文字；键盘 focus 给 1px 焦点环或下划线，不用常驻填充。

什么时候才加底框

标签超过 5 个、或对比度太低时，才加 hover 时的轻填充；常驻底框仍然不需要。
