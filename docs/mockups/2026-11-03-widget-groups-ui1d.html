island：保留每个组件一个 tile

不把组折叠成一个 tile。组的成员仍各自出现在 island 上；右上角小角标表示“同组”，只有当前标签显示 open 环。

1组关闭：点组内任意 tile → 打开组并切到该标签。
2组已打开：点另一个组内 tile → 只切标签，不关组、不重复开窗。
3点 active tile：像现在一样收起组窗口。
4右键 tile：成员菜单 + “切换到该标签 / 分离此组件 / 隐藏整组”。
5角标 2：表示同组；悬停 tooltip 列出组内组件名，不额外占 island 宽度。
6删除/分离：组内剩 1 个时自动解散；island 立即回到普通 tile，不再显示角标。
