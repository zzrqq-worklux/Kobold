放置规则推荐默认 · 待确认
  1. 默认：成员段直接接在 island 右侧；左缘不动；同一 capsule。
  2. 右缘不足：整条展开后的 island 左移 clamp，右缘保留 16 DIP；不是单独移动成员段。
  3. 不翻转：不把成员段放到 island 左侧；保持同一 capsule 的阅读方向。
  4. 垂直不足：整条 island 上移 / 下移 clamp，始终保留 16 DIP。

成员段不是独立窗口；位移作用于整条 capsule，接缝、圆角、阴影才不会断开。翻转会让同一组在两次打开时左右跳，v1 不采用。

交互与状态

点击、pin、失焦与解散各只有一条默认路径；所有 pin 都是“按成员”，不是整组开关。

操作点击 / 键盘
点组 tile

island 在同一表面内向右展开；再点一次收起。组窗口不受影响。

点成员

打开组窗口并切到该标签；island 收起成员段，回到折叠态。

点外部 / Esc

只收起 island 的成员段；鼠标移出不收起；组窗口再按 pin / 失焦规则决定是否收起。

成员格 pin / 右键

固定或取消该成员；成员格右上角显示金色 pin，右键菜单提供同一项。

组窗口 header pin

只固定 / 取消当前 active 成员；其他成员的 pin 不变。

状态pin / 失焦 / 组变化
全部未固定

组窗口失焦 → 收起（沿用现有行为）。

任一成员固定

组窗口失焦 → 保持打开，即使当前 active 成员本身未固定。

active 切换

open ring 立即移动；header pin 跟随 active；meta 的“已固定数”不变。

合并 / 分离

组 tile 缩略图立即重画；island 行不重建、不闪。

解散 / 剩 1 个

组 tile 消失，普通 44×44 tile 回到原位；不保留 Folder 容器。

PIN 按成员

已固定 = 金色直立；未固定 = hover 才出现 45° 灰。折叠组 tile 不挂 pin。

OPEN RING 只给 ACTIVE

只在展开的 island 成员段标记当前成员；组窗口内仍用 2px underline，不叠第二种 active 指示。

+3
组 tile 打开

只加中性 group-open 外环；不把 active 成员色带到折叠 tile，避免误读成某个成员。

+3
溢出 = 3 + N

最多 4 个可视格：4 人全画；5 人以上画前 3 个 + +N，不堆叠第 4 个图标。

右缘不足

04待确认

Pin 语义

任一成员 pin 就保持组窗口；全部未 pin 才失焦收起。header pin = active member。

05待确认

Open ring

只给展开成员段的 active 成员；组窗口仍用 2px underline，折叠 tile 不给成员色环。

06待确认

Pin 字形

已 pin 的成员格显示金色 pin；折叠组 tile 不显示。未 pin 只在 hover 露出 45° 灰。

07待确认

组 tile 打开时

中性 group-open 外环；不在折叠 tile 上标 active 成员，active 只在展开的 island 成员段里。
