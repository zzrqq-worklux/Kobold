不同尺寸怎么处理

组窗口只有一套尺寸。成员自己的宽高只在合并和分离时参与计算；切换标签时不跳窗，内容按共享视口重排。

合并时

组窗口取“目标尺寸 / 新成员首选 / 所有成员最小”的最大值，再 clamp 到工作区。新成员更大，组长大；新成员更小，组不缩。

切换时

组窗口尺寸不变。当前 View 铺满共享视口并重排：Todo 日历/列表、Note 卡片、Folder 列数都按这个视口算。

分离时

独立窗口恢复该组件自己记住的宽高（例如笔记回 300×380），不继承组窗口的 760×540。

下限

组最小尺寸 = 所有成员最小尺寸的最大值；拖动组边框不会小于它，避免切到某个标签时内容被裁。

尺寸仅示意 组内不做 per-tab resize 成员尺寸只在分离时恢复 大组件进来，组长大；小组件进来，组不缩
