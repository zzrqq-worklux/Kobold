# Kobold 灵动岛（Island）实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 用屏幕顶部居中的"灵动岛"取代桌面文件夹图标——岛收起时是一个小药丸，hover 时展开显示各 widget 图标，点击图标呼出对应面板（面板收起即隐藏）；保留 lock（内容锁）与 pin（面板失焦不收起）。

**Architecture:** 新增 `IslandWindow`（顶部居中、Topmost、透明、无任务栏）作为唯一入口与状态机（collapsed 药丸 / expanded 图标行）。`FolderWidget` 从"桌面图标+面板"改造为"纯面板窗口"，由岛按其算好的位置显隐。`WidgetManager` 负责创建岛、把 widget 列表喂给岛、并协调面板显隐。

**Tech Stack:** WPF (net48)、C# 7.3、现有 `IconRendererFactory`（复用 widget 图标渲染）、`DispatcherTimer` + `DoubleAnimation`（收起/展开动画）。

## Global Constraints

- 目标框架 net48，`LangVersion 7.3`；所有 UI 文案走 `Localization`（en/zh/ja 三语，`tests/LangCheck` 守护 key 集合一致）。
- 显示缩放：进程已声明 PerMonitorV2（`app.manifest`）；涉及屏幕坐标一律用 WPF 单位（DIP），窗口尺寸/位置用 `SystemParameters`。
- 岛的参数（本计划定稿值）：收起态药丸 120×8（窗口含透明热区 300×10，便于 hover）；展开态高 56，每 widget 入口 44×44，间距 8；无操作 4s 或鼠标离开 1.5s 自动收起；贴屏顶 y=0，水平居中。
- 面板位置：固定从岛下方展开（水平居中），不做自由拖动（简化）；面板宽度=现有 `CalculatePanelSize()`，高度同理。
- 保留：`lock`（禁止内容移入移出，菜单/拖拽仍在 `FolderWidget` 内）、`pin`（面板失焦/失焦后不收起）。
- 每个阶段结束后必须：`dotnet build Kobold.csproj -c Debug` 0 错误；改动含新词条时 `tests/LangCheck` 全绿。
- 临时验证脚本放 `%TEMP%\opencode\`，不进仓库。提交信息用 conventional commits（`feat(island): ...`）。

## 阶段 1：灵动岛外壳（可运行的岛）

**Files:**
- Create: `Controls/IslandWindow.xaml`、`Controls/IslandWindow.xaml.cs`
- Modify: `Core/WidgetConstants.cs`（岛尺寸常量）
- Modify: `App.xaml.cs`（启动时创建岛）

**Interfaces:**
- Produces: `IslandWindow` 类，含 `void SetWidgets(IEnumerable<FolderData>)` 与事件 `event Action<string> WidgetActivated`（folderId）。
- 常量：`ISLAND_PILL_WIDTH=120`、`ISLAND_PILL_HEIGHT=8`、`ISLAND_HOVER_WIDTH=300`、`ISLAND_HOVER_HEIGHT=10`、`ISLAND_EXPANDED_HEIGHT=56`、`ISLAND_TILE_SIZE=44`、`ISLAND_TILE_GAP=8`、`ISLAND_COLLAPSE_DELAY_MS=4000`、`ISLAND_LEAVE_DELAY_MS=1500`。

**行为：**
- Window：`WindowStyle=None`、`AllowsTransparency=True`、`Background=Transparent`、`Topmost=True`、`ShowInTaskbar=False`、`ResizeMode=NoResize`。
- 位置：`Left=(SystemParameters.PrimaryScreenWidth-Width)/2`、`Top=0`。
- collapsed：窗口 300×10，内部 120×8 圆角药丸居中（深色半透明 `#CC202020` + 圆角 4）。
- expanded：窗口宽=`24 + N*(44+8)`、高 56，圆角胶囊背景 `#E6202020`，内横排各 widget 图标入口（阶段 1 用占位图标，阶段 2 接真图标）。
- `MouseEnter` 于窗口 → 展开；`MouseLeave` → 启动 1.5s 收起定时器；展开后启动 4s 无操作收起定时器；任何交互重置。
- 动画：宽度/高度 `DoubleAnimation`（180ms）并同步重算 `Left` 保持居中。

## 阶段 3：FolderWidget 改为纯面板（去掉桌面图标）

**Files:**
- Modify: `Controls/FolderWidget.xaml`（岛模式下隐藏 `FolderIconGrid`/`FolderNameText`）
- Modify: `Controls/FolderWidget.xaml.cs` / `Interactions.cs` / `Theme.cs`（岛模式分支）
- Modify: `Core/WidgetManager.cs`（创建 widget 时不显示桌面形态）

**行为：**
- widget 创建即处于"面板待命"：窗口隐藏，`FolderIconGrid`/`FolderNameText` `Collapsed`，`ExpandedPanel` `Canvas.Left=0`，窗口尺寸=面板尺寸。
- `ShowPanelHere` → 按岛算的位置显示面板；`HidePanel` → 窗口 `Hide()`。
- `Window_Deactivated`：未 pin → `HidePanel`；pin → 保持。
- `Esc`：未 pin → `HidePanel`；pin → 只清选择。
- 面板内拖动 widget 窗口不再需要（岛定位）；保留 lock 内容锁与其菜单/拖拽约束不变。
- 不再调用 `TogglePanel` 的"图标↔面板"几何逻辑（岛模式走新的显隐路径）。

**任务：**
- [ ] 3.1 岛模式：构造函数隐藏图标元素、`ExpandedPanel` 归位为左 0。
- [ ] 3.2 新增 `HidePanel()`；`ShowPanelHere` 用它配对；`Deactivated`/`Esc` 改走 `HidePanel`（pin 分支保留）。
- [ ] 3.3 `WidgetManager`：widget 不再 `Show()` 桌面窗口（初始 `Hide()`），只由岛呼出；`ShowAll`/`HideAll` 语义改为"展开所有面板 / 收起所有面板"。
- [ ] 3.4 构建 + 启动：桌面**不再有**文件夹图标；点击岛内图标 → 面板出现；点空白 → 收起（未 pin）/保持（pin）；lock 仍生效。
- [ ] 3.5 提交 `feat(island): make folder widgets panel-only, driven by the island`。

**验证：** 手动观察上表；确认 lock 菜单/拖拽限制仍工作、pin 面板不因失焦收起。
