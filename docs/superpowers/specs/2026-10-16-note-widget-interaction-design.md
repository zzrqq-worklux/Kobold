## 0. 决策记录（2026-10-16 用户逐条确认）

1. **痛点确认（六项全中）**：进编辑三跳、离开有仪式、读写分家、预览要手动切、新建也跳页、
   只是看一眼也要下钻——三态模型整体推翻，重做为「读写同面 + 零仪式」。
2. **前提校准**：PaperTodo / Obsidian 的「即时预览」本质是同一文本控件内的标记塌缩
   （PaperTodo 为 AvalonEdit 行变换器管线）。Kobold 零新依赖约束下本轮做**交互等价物**
   （读写同面、打字即渲染、零仪式）；引擎级 WYSIWYG 不做进本轮，留作将来单独评估。
3. **承载方式 = 甲「就地工作台」**：列表是唯一容器；卡片两态（卡面 ⇄ 展开面）；一次只展开
   一张；＋ 原地起笔；全程零跳页。
4. **面模型**：读态＝预览铺满；写＝点哪写哪（块级定位光标）；写态＝预览上＋源码下（各半、
   实时渲染）；写态 Esc 回读态，读态 Esc / Backspace / ‹ 收起。
5. **全自动保存、零提交**：输入 → 内存 + 既有防抖保存通道；无提交 / 取消 / 回滚概念；
   空稿离场丢弃沿用现行规则。
6. **新建流**：＋（及空白右键新建）→ 新卡置顶、直接展开写态——「在列表里直接起笔」。
7. **明确不做**：引擎级 WYSIWYG、可拖分栏、「打字即编辑」（CJK 输入法可靠性）、失焦自动
   收起；上一轮的旧非目标（图片/附件/搜索等）维持。

## 1. 目标与成功标准

痛点 → 解法的逐条映射（验收的主轴）：

| # | 原痛点 | 升级后 |
|---|---|---|
| 1 | 进编辑三跳 | 点哪写哪：读态点正文一次即进写态；新建直接写态。**0 跳**。 |
| 2 | 离开有仪式 | 无提交/取消/回滚；收起即走，全程自动保存。 |
| 3 | 读写分家 | 同一个展开面：读＝预览铺满，写＝预览+源码同屏。 |
| 4 | 预览要手动切 | 写态预览常驻、打字即渲染（节流）；无段控。 |
| 5 | 新建跳页 | ＋ 置顶 + 原地展开写态，光标就位。 |
| 6 | 看一眼也要下钻 | 点卡片就地展开为渲染全文；点空白/‹ 即刻收起，零仪式。 |

成功标准：

1. 交互预算：读一眼 = 1 击进（点卡）+ 1 击出（点空白/‹）；改一处 = 进读后 1 击
   （点哪写哪）；新建起笔 = 1 击（＋ 直接写态）；离开写作 = 1 击（Esc 回读）；
   离开卡片 = 1 击（点空白/‹）。
2. 半成品文本在收起 / 切卡 / 面板隐藏 / 退出 / 关机路径下零丢失（走既有冲刷 + 保存通道）。
3. 文件夹 / 待办组件与 Core 纯逻辑零回归；`NoteMarkdownCheck` 全绿不动。
4. 全量自检维持 32/32（矩阵不加行；`XamlLoadCheck` 笔记组 pins 重写，`LangCheck` 同步键表）。
5. README（英/中）与 CHANGELOG「Unreleased」按新交互改写；冒烟清单重写。

## 2. 非目标（明确不做）

- **引擎级 WYSIWYG / 标记塌缩**（同控件内渲染）——将来单独评估，本轮不做。
- 可拖拽的预览/源码分栏比例；面板级的多笔记并排。
- 「打字即编辑」（读态直接敲键盘进写态）：CJK 输入法绑定焦点元素，可靠性差；v1 用
  「点哪写哪」。
- 失焦自动收起（点其它窗口不收起）；悬停预览；卡片摘要加行。
- 上一轮非目标维持：图片/附件、嵌套列表/引用、搜索/标签/排序、导出、键盘导航列表、
  相对时间、发版动作。

## 3. 结构与状态模型（`Controls/NotePanelView`）

### 3.1 列表成为唯一容器

- 旧的 ListHost / ReadingHost / EditingHost 三容器与 `State { List, Reading, Editing }` 枚举
  **整体退役**。列表（`ItemsScroller` + `ItemsPanel` + `＋` 行）是唯一常驻容器。
- 每张卡有两种形态：
  - **卡面**：现行结构不变（标题 14 粗、时间 `g`、两行摘要、任务进度、悬浮底色、行菜单）。
  - **展开面**：长在卡片原位置（手风琴），由新组件 `NoteSurfaceView` 承载（§4）。
- 展开状态 = `_expandedId`（按 `NoteItem.Id` 记忆）+ `_writing`（本次展开会话是否写态）。
  全程**一次只展开一张**：展开新卡前先收起旧卡。

### 3.2 展开 / 收起的编排

- 卡面单击 → `Expand(note)`：若已有展开卡先 `Collapse()`（冲刷 + 空稿判定 + 需要时 notify），
  再展开目标；新条目的初始形态 = 写态（§6），已有条目 = 读态（§4.1）。
- 收起入口：展开面左上角的浮动 `‹`；点面板空白（非卡片、非 ＋ 行的区域）；读态下的
  Esc / Backspace；展开面被数据侧移除（删除/撤回时的防御性收起）。
- 收起动作：`Flush()`（§5.2）→ 空稿判定（§4.5）→ 重建列表（按最新 ModifiedAt 归位）。
- 展开 / 收起不改变卡片顺序假设：**展开期间列表不重建、不重排**（正在写的卡不跳位）；
  顺序在收起后的重建里落定。
- 展开一张不在当前视口的卡（＋ 新建已置顶，天然可见）时滚动到其可见位置；收起保持偏移。

### 3.3 展开面的 chrome 与既有入口

- 展开面只保留浮动 `‹`（×22 圆角，沿用现有按钮画法）；不放标题栏、不放时间（内容即标题，
  元信息收起后可见）。
- 删除入口保持「卡面行菜单」；展开态不提供删除（收起后可删）。
- 空白右键「新建」、卡面右键删除、列表态 Ctrl+Z 撤回栈（≤20）全部保持现状。

## 4. 面内的读与写（`Controls/NoteSurfaceView`）

新组件 `NoteSurfaceView`（UserControl，独立可测；将来若换成整面承载——备选乙——可原样复用）：

```
读态（默认）                     写态（点哪写哪）
┌─────────────────────────┐    ┌─────────────────────────┐
│ ‹                       │    │ ‹                       │
│                         │    │  渲染预览（约上½，实时刷新）│
│  渲染全文铺满            │    │ ─────────────────────── │
│  （任务框可点、链接可点）  │    │  源码框（约下½，可写）      │
│                         │    │                         │
└─────────────────────────┘    └─────────────────────────┘
```

### 4.1 读态

- 渲染全文（`NoteMarkdownRenderer.Build(MarkdownParser.Parse(note.Text), …)`）铺满展开面。
- 任务框可点：回写源码（`NoteOps.ToggleTaskAt`）→ `ModifiedAt` 更新 → 重渲染 →
  滚动位置保持（沿用「先记 offset、重渲染后 Dispatcher 恢复」的现有做法）。
- 链接可点：http/https 走系统浏览器（现有 `OpenLink`）。
- 键盘：Esc / Backspace = 收起。焦点路径按现行先例处理（展开后把焦点交给可路由的元素，
  保证隧道键可达；见上一轮 `ReadingBox.Focus()` 的教训）。

### 4.2 写态与「点哪写哪」

- 读态下点预览正文（段落/标题/列表行/引用/代码块/表格等块级内容）→ 进写态：
  源码框打开并以该处为光标落点。定位粒度 = **块级**：解析器已有绝对行号
  （`MdBlock.Line`，任务框已按行回写），渲染时给块级元素挂 `Tag = 起始行`；点击从
  `e.OriginalSource` 上溯取到行号 → `TextBox.GetCharacterIndexFromLineIndex` 换算光标并
  滚动到该行。表格 / 代码块按块的起始行定位。
- **点任务框 / 链接不进入写态**：这两类命中已在渲染器里 `Handled`；块级入写处理器需显式
  排除（判定命中祖先链），并有 pin 保护（§8）。
- 写态排布：上＝预览（约一半），下＝源码框（约一半）；两个方向都带滚动。
- 写态下预览保持可交互：任务框点击 → 源码框文本同步翻转（字符替换等长，光标不漂）+
  预览重渲染；链接照常打开。
- 写态键盘：Esc = 回读态（不丢字——文本早已自动保存）；Backspace 归文本编辑。
- 写态源码框的**右键快速插入菜单**（T15 全套：标准四命令 + 标题/格式子菜单 + 平铺七项）
  原样接管到本组件的源码框；`NoteEditorOps` 与三语占位词零变化。

### 4.3 实时渲染

- 写态下源码框 `TextChanged` → ~200ms 节流：写数据（§5）+ 通知 + 预览重渲染（保留预览滚动）。
- 进写态、回读态时各强制渲染一次（回读态展示的必是最终文本）。
- 超长笔记性能入观察项（流式渲染的既有风险延续）；节流间隔如冒烟显示不足再调。

### 4.4 读态 ⇄ 写态 ⇄ 收起的完整手势表

| 当前 | 手势 | 结果 |
|---|---|---|
| 列表 | 点卡面 | 收起其它、展开目标（读态；新条目直接写态） |
| 读态 | 点正文 | 进写态，光标到点中块 |
| 读态 | 点任务框 / 链接 | 原行为（回写 / 打开），不换态 |
| 读态 | Esc / Backspace / ‹ / 点空白 | 收起回列表 |
| 写态 | Esc / ‹ | 回读态 |
| 写态 | 点其它卡面 / 点空白 | 收起旧卡（冲刷）并展开新卡 / 收起回列表 |
| 任意 | 面板隐藏 / 关闭 / 关机 | 冲刷后走（展开态本身保留，面板重开仍在原态） |

### 4.5 空稿丢弃（沿用现行规则，判定点前移）

- 收起（含切卡与面板冲刷）时，文本 Trim 后为空 → **整条丢弃**（新建与存量同规，与现行
  「编辑中清空的笔记离场时丢弃」一致）。
- 丢弃是数据变化：从 `Notes` 移除 + 走通知路径（防止「内存删了、磁盘还留着」的复活路径，
  沿用 T14 的收敛教训）。

## 5. 保存与生命周期

### 5.1 自动保存（零新机制）

- 数据可靠性建立在既有通道上：`NotifyDataChanged()` → `WidgetManager` → `AppConfig.SaveDebounced()`
  （1s 防抖 + 强制上限定时器）+ 岛刷新；写入是原子的（`AtomicFile`）。
- 写态节流 tick：`note.Text` 有真变才写回 + `ModifiedAt = DateTime.Now` + `NotifyDataChanged()`。
- **无提交 / 取消 / 回滚**：Esc 不丢字；源码框内 Ctrl+Z 是 WPF 原生文本撤销，数据随文本走
  （语义自洽）；列表态 Ctrl+Z 仍是删除撤回（焦点在源码框内时不动撤回栈——沿用
  `Keyboard.FocusedElement is TextBox` 判定）。

### 5.2 冲刷点（半成品零丢失）

`Flush()` = 节流器未落盘的内容立即写数据 + 通知；调用点：

- 收起（切卡 / ‹ / 点空白 / 读态 Esc/Backspace）；
- `NoteWidget.OnPanelHidden()`（收起面板，既有钩子，改调新的 Flush + 空稿判定）；
- `NoteWidget.Closing`（关闭，同上）；
- 退出/关机路径由既有 `BeginExitSave` 承担（数据已在内存即安全）。

`NoteWidget.CommitPendingEdit()` 更名为 `FlushPendingEdit()`（语义：冲刷 + 空稿判定；
幂等），钩子位置不变。

### 5.3 其他保持

- 时间戳语义：`CreatedAt` 建卡时给定；`ModifiedAt` 只在文本真变时更新（沿用）。
- 数据格式零变化：`NoteData` / `NoteItem` / JSON / 修复 / 迁移 / 转换器全部不动；
  旧版本读到含 note 的配置行为不变（`config.json.failed-*` 兼容叙述照旧）。

## 6. 新建流

- ＋ 行与列表空白右键「新建」→ 同一入口 `StartNewNote()`：新 `NoteItem`（Guid、Now 时间戳、
  空文本）插到 `Notes` 头部（显示序天然置顶）→ 展开 + 写态（源码框聚焦、光标就位）→
  预览半区随打字生长。
- 空稿离场（收起/切卡/面板冲刷）→ 丢弃消失，不留空卡（§4.5）。
- 列表为空时：＋ 行照旧是唯一内容（现状）。

## 8. 测试与验收

### 8.1 自检矩阵（维持 32 行，不新增工程）

  5. 写态进入：点正文块（合成事件 / 直调处理器）→ `_writing`、源码框文本、光标 = 块起始行换算；

  11. 写态 Esc 回读态（不丢字、不收起）；
  12. 快速插入菜单：既有 T15 pins 迁移到新组件（不改断言语义）；
  13. 删除 + 撤回栈不回归（既有 pins 保持）；
  14. 主题/语言刷新：写态中途 `Refresh()` 不打断文本（护栏 pin）。
- `LangCheck`：键表同步（删 2 键）。
- `MenuRenderCheck`：不回归（菜单模板未动）。

### 8.2 冒烟清单（用户手动，部署后重写）

1. 展开/收起：点卡片就地展开渲染全文；点空白 / ‹ / Esc / Backspace 即回；顺序按最近编辑。
2. 点哪写哪：点段落/标题/列表/表格任一处 → 源码框就位、光标落到对应行；打字即回渲染。
3. 仅阅读路径：任务框点击回写并保持滚动；链接单次打开；读态不进任何编辑面。
4. 写态：预览实时刷新；Esc 回读态；再收起；重复进出无卡顿。
5. 自动保存：输入后不收起直接隐藏面板 / 退出 → 重开文本完整；无丢字路径。
6. 空稿：＋ 后不写就切走 / 收起 → 空卡消失。
7. 新建：＋ 在列表顶部直接起笔；空白右键同。
8. 快速插入：写态右键全套菜单（含 Ctrl+Z 单步撤回）。
9. 删除撤回：行菜单删除 + 列表态 Ctrl+Z 多步找回。
10. 三主题 / 三语 / 高对比度下展开面与写态样式正确。
11. 回归抽查：文件夹 / 待办原有行为。
12. 全量自检 `Run-Checks.ps1 -Group all` 32/32。
