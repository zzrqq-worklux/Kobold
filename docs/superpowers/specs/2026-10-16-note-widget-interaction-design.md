## 0. 决策记录（2026-10-16 两轮用户逐条确认）

1. **痛点确认（六项全中）**：进编辑三跳、离开有仪式、读写分家、预览要手动切、新建也跳页、
   只是看一眼也要下钻——三态模型整体推翻，重做为「读写同面 + 零仪式」。
2. **逐字符塌缩 = 引擎工程，不做进本轮**：PaperTodo / Obsidian 的字面机制依赖可扩展的文本
   渲染管线（AvalonEdit 塌缩/标记槽/显灵）；WPF 原生 `TextBox` / `RichTextBox` 无此扩展点，
   绕行三条路（移植 AvalonEdit / 自研编辑器 / 富文本直编破坏 Markdown 数据模型）代价全部
   错位。留作将来单独评估项。
3. **面形态 = 块级行内编辑**（第二轮改选，取代早先的 split 双栏草案）：点中的块**原地**变
   源码编辑框，其余内容保持渲染、位置不动；离开即渲染回去。与 PaperTodo 的交互范式
   近乎同构（点击正文就地编辑、离开即回到渲染视图、零按钮）。
4. **承载 = 甲「就地工作台」**：列表是唯一容器；卡片两态（卡面 ⇄ 展开面）；一次只展开一张；
   ＋ 原地起笔；全程零跳页。
5. **面模型**：渲染态（默认，全文渲染 + 任务框/链接可点）⇄ 块编辑态（前段渲染 / 该块源码
   框 / 后段渲染，单滚动区）；进入 = 点哪写哪（行级定位、块级兜底）；离开 = 提交 + 渲染回去。
6. **全自动保存、零提交**：输入 ~400ms 节流拼接回数据 + 既有防抖保存通道；离开 / 切卡 /
   面板隐藏 / 关闭 = 立即冲刷；无提交 / 取消 / 回滚概念；空稿离场丢弃沿用现行规则。
7. **新建流**：＋（及空白右键新建）→ 新卡置顶、直接进入块编辑（空文本的编辑区域 = 全文）。
8. **明确不做**：逐字符塌缩；块内逐键实时渲染与「预览窄条」（v1 不做，留作后续增强候选）；
   可拖分栏；「打字即编辑」（CJK 输入法可靠性）；失焦自动收起；上一轮的旧非目标维持。

## 1. 目标与成功标准

痛点 → 解法的逐条映射（验收的主轴）：

| # | 原痛点 | 升级后 |
|---|---|---|
| 1 | 进编辑三跳 | 点哪写哪：点中的块原地变成编辑框（1 击）；新建直接起笔。**0 跳**。 |
| 2 | 离开有仪式 | 无提交/取消/回滚；离开块即渲染、离开卡片即收起，全程自动保存。 |
| 3 | 读写分家 | 同一个展开面：读＝渲染态，写＝块编辑态（点哪写哪，其余内容原位保持）。 |
| 4 | 预览要手动切 | 渲染常驻：除正在编辑的那块外，全文一直是渲染好的；离开即渲染回去，无段控。 |
| 5 | 新建跳页 | ＋ 置顶 + 原地进入块编辑，光标就位。 |
| 6 | 看一眼也要下钻 | 点卡片就地展开为渲染全文；点空白/‹ 即刻收起，零仪式。 |

成功标准：

1. 交互预算：读一眼 = 1 击进（点卡）+ 1 击出（点空白/‹）；改一处 = 1 击（点该块进入编辑）
   + 1 击（Esc/点下一块离开）；新建起笔 = 1 击（＋）；离开卡片 = 1 击（点空白/‹）。
2. 半成品文本在收起 / 切卡 / 切块 / 面板隐藏 / 退出 / 关机路径下零丢失（节流拼接 +
   离开冲刷 + 既有保存通道）。
3. 文件夹 / 待办组件零回归；Core 纯逻辑既有 pins 零回归（仅新增块范围纯函数）。
4. 全量自检维持 32/32（矩阵不加行；`XamlLoadCheck` 笔记组 pins 重写，`NoteMarkdownCheck`
   增补块范围 pins，`LangCheck` 同步键表）。
5. README（英/中）与 CHANGELOG「Unreleased」按新交互改写；冒烟清单重写。

## 3. 结构与状态模型（`Controls/NotePanelView`）

### 3.1 列表成为唯一容器

- 旧的 ListHost / ReadingHost / EditingHost 三容器与 `State { List, Reading, Editing }` 枚举
  **整体退役**。列表（`ItemsScroller` + `ItemsPanel` + `＋` 行）是唯一常驻容器。
- 每张卡有两种形态：
  - **卡面**：现行结构不变（标题 14 粗、时间 `g`、两行摘要、任务进度、悬浮底色、行菜单）。
  - **展开面**：长在卡片原位置（手风琴），由新组件 `NoteSurfaceView` 承载（§4）：渲染态为
    单一 RichTextBox；块编辑态为「前段渲染 / 源码编辑框 / 后段渲染」三段合成、单滚动区。
- 展开状态 = `_expandedId`（按 `NoteItem.Id` 记忆）+ 块编辑会话（编辑区域的行范围）。
  全程**一次只展开一张**；同一时刻至多一个块处于编辑。

### 3.2 展开 / 收起的编排

- 卡面单击 → `Expand(note)`：若已有展开卡先 `Collapse()`（冲刷 + 空稿判定 + 需要时 notify），
  再展开目标；新条目的初始形态 = 块编辑（空区域，§6），已有条目 = 渲染态（§4.1）。
- 收起入口：展开面左上角的浮动 `‹`；点面板空白（非卡片、非 ＋ 行的区域）；渲染态下的
  Esc / Backspace；展开面被数据侧移除（删除/撤回时的防御性收起）。
- 收起动作：`Flush()`（§5.2）→ 空稿判定（§4.5）→ 重建列表（按最新 ModifiedAt 归位）。
- **展开期间列表不重建、不重排**（正在编辑的卡不跳位）；顺序在收起后的重建里落定。
- 展开卡进入视口（＋ 新建已置顶，天然可见）；收起保持偏移。

### 3.3 展开面的 chrome 与既有入口

- 展开面只保留浮动 `‹`（×22 圆角，沿用现有按钮画法）；不放标题栏、不放时间（内容即标题，
  元信息收起后可见）。
- 删除入口保持「卡面行菜单」；展开态不提供删除（收起后可删）。
- 空白右键「新建」、卡面右键删除、列表态 Ctrl+Z 撤回栈（≤20）全部保持现状。

## 4. 面的两种形态（`Controls/NoteSurfaceView`）

新组件 `NoteSurfaceView`（UserControl，独立可测；将来若换整面承载也可原样复用）：

```
渲染态（默认）                          块编辑态（点哪写哪）
┌─────────────────────────┐        ┌─────────────────────────┐
│ ‹                       │        │ ‹                       │
│                         │        │  （前段）渲染不变         │
│  渲染全文（单 RTB）       │        │ ▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒ │
│  任务框可点、链接可点      │        │  该块源码（可写；字号/   │
│                         │        │  等宽按块类型匹配）       │
│                         │        │ ▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒ │
│                         │        │  （后段）渲染不变         │
└─────────────────────────┘        └─────────────────────────┘
```

### 4.1 渲染态

- 渲染全文（`NoteMarkdownRenderer.Build(MarkdownParser.Parse(note.Text), …)`）铺满展开面。
- 任务框可点：回写源码（`NoteOps.ToggleTaskAt`）→ `ModifiedAt` 更新 → 重渲染 →
  滚动位置保持（沿用「先记 offset、重渲染后 Dispatcher 恢复」的现有做法）。
- 链接可点：http/https 走系统浏览器（现有 `OpenLink`）。
- 键盘：Esc / Backspace = 收起。焦点路径按现行先例处理（展开后把焦点交给可路由的元素，
  保证隧道键可达；沿用上一轮 `ReadingBox.Focus()` 的教训）。

### 4.2 进入块编辑（点哪写哪）

- 渲染态下点某个块 → 该块**原地**进入编辑：其余内容位置不动，该块位置换成源码编辑框。
- **定位 = 行级**：渲染时把行号挂载到渲染元素上（`Tag` / 附加属性，任务框已按行回写的先例）；
  点击从 `e.OriginalSource` 上溯取行号 → 该行的所属**块**（顶层块）源码行范围
  （`NoteBlockRanges`，§5.4）→ 编辑器内容 = 区域源码，光标 = 点中的那一行；命中不到
  行级时降级为块起始行（表格 / 代码块天然只有块起始行）。
- **点任务框 / 链接不进入编辑**：两类命中已被渲染器 `Handled`；块进入处理器需显式排除
  （判定命中祖先链），并有 pin 保护（§8）。
- 编辑框的字体/字号**按块类型匹配**：标题块用标题阶梯字号、代码块等宽、引用块带缩进；
  正文用正文字体。目的 = 进出编辑时的视觉跳动尽量小（最小集：字号 + 等宽；其余为打磨项）。

### 4.3 块编辑态

- 合成：`前段`（blocks[0..i) 渲染）+ `编辑框`（该块源码）+ `后段`（blocks[i+1..) 渲染），
  单滚动区；**前 / 后段为静态渲染**（回调为空）：任务框不响应、链接不导航——编辑期间
  不产生并发数据改写。点前/后段 = 提交当前块并切换到该块编辑（§4.4）。
- 输入 → ~400ms 节流：**拼接回数据**（区域文本重写同范围）+ `ModifiedAt`（真变才更新）+
  `NotifyDataChanged()`。拼接幂等（同区域重写同文本为 no-op）。
- 离开编辑（Esc / 切到另一块 / 点空白 / `‹` / 切卡 / 面板隐藏 / 关闭）→ **立即拼接**
  （节流器里未落盘的先落）→ 单 RTB 重渲染（保留滚动）。
- 编辑期间列表不重排、面不因 `Refresh()` 重建（主题/语言切换只重绘 chrome 与前后段样式，
  不打断编辑框状态——护栏 pin）。
- 写态源码框的**右键快速插入菜单**（T15 全套：标准四命令 + 标题/格式子菜单 + 平铺七项）
  原样接管到本组件的编辑框；`NoteEditorOps` 与三语占位词零变化。
- 超长块（大代码块/表格）编辑框自动高度，滚动由外层承载；性能入观察项。

### 4.4 完整手势表

| 当前 | 手势 | 结果 |
|---|---|---|
| 列表 | 点卡面 | 收起其它、展开目标（渲染态） |
| 列表 | ＋ / 空白右键新建 | 新卡置顶 + 展开 + 块编辑（空区域） |
| 渲染态 | 点块正文 | 该块进入编辑；其余内容原位保持、光标到点中的行 |
| 渲染态 | 点任务框 / 链接 | 原行为（回写 / 打开），不进入编辑 |
| 渲染态 | Esc / Backspace / ‹ / 点空白 | 收起回列表 |
| 编辑中 | Esc | 提交该块 + 渲染回去（仍展开） |
| 编辑中 | 点另一块 | 提交当前块 + 切换编辑该块 |
| 编辑中 | 点其它卡面 / 点空白 / ‹ | 提交 + 收起旧卡（并展开新卡 / 回列表） |
| 任意 | 面板隐藏 / 关闭 / 关机 | 提交当前块后走（展开态保留，面板重开仍在原态） |

### 4.5 空稿丢弃（沿用现行规则）

- 收起（含切卡与面板冲刷）时，文本 Trim 后为空 → **整条丢弃**（新建与存量同规，与现行
  「编辑中清空的笔记离场时丢弃」一致）。
- 丢弃是数据变化：从 `Notes` 移除 + 走通知路径（防止「内存删了、磁盘还留着」的复活路径，
  沿用 T14 的收敛教训）。

## 5. 保存与生命周期

### 5.1 自动保存（零新机制）

- 数据可靠性建立在既有通道上：`NotifyDataChanged()` → `WidgetManager` → `AppConfig.SaveDebounced()`
  （1s 防抖 + 强制上限定时器）+ 岛刷新；写入是原子的（`AtomicFile`）。
- 块编辑节流 tick：区域拼接 + `ModifiedAt = DateTime.Now`（真变才更新）+ `NotifyDataChanged()`。
- **无提交 / 取消 / 回滚**：Esc 不丢字；编辑框内 Ctrl+Z 是 WPF 原生文本撤销，数据随文本走
  （语义自洽）；列表态 Ctrl+Z 仍是删除撤回（焦点在编辑框内时不动撤回栈——沿用
  `Keyboard.FocusedElement is TextBox` 判定）。

### 5.2 冲刷点（半成品零丢失）

`Flush()` = 节流器未落盘的区域立即拼接 + 通知；调用点：

- 离开块（Esc / 切块 / 点空白 / `‹`）；
- 收起（切卡 / 点空白 / 渲染态 Esc、Backspace）；
- `NoteWidget.OnPanelHidden()`（收起面板，既有钩子，改调新的 Flush + 空稿判定）；
- `NoteWidget.Closing`（关闭，同上）；
- 退出/关机路径由既有 `BeginExitSave` 承担（数据已在内存即安全）。

`NoteWidget.CommitPendingEdit()` 更名为 `FlushPendingEdit()`（语义：冲刷 + 空稿判定；
幂等），钩子位置不变。

### 5.3 其他保持

- 时间戳语义：`CreatedAt` 建卡时给定；`ModifiedAt` 只在文本真变时更新（沿用）。
- 数据格式零变化：`NoteData` / `NoteItem` / JSON / 修复 / 迁移 / 转换器全部不动；
  旧版本读到含 note 的配置行为不变（`config.json.failed-*` 兼容叙述照旧）。

### 5.4 块范围纯函数（新 `Core/NoteBlockRanges.cs`）

块 → 源码行范围的切出与拼接，全部纯逻辑、可逐条 pin：

```csharp
public static class NoteBlockRanges
{
    // 顶层块的行范围（[Start, End) 半开区间，行号 0 基、跨行自然排序）：
    // Start = 该块首行；End = 下一块首行（末块 = 文本总行数）。
    public static List<(int Start, int End)> RangesOf(string text);

    // 行号 → 所属范围下标（夹取到最近的下方范围）；无块时 -1。
    public static int RangeIndexAtLine(string text, int line);

    // 提取行区间文本（行分隔符原样保留，CRLF 与 LF 均不破坏）。
    public static string ExtractLines(string text, int start, int end);

    // 用 replacement 替换行区间，返回新文本；越界钳位；幂等（同区间同文本为 no-op）。
    public static string ReplaceLines(string text, int start, int end, string replacement);
}
```

- 语义要点：范围归属含块间空行（[Start, nextStart)），保证「首尾空行不参加编辑、拼接不
  丢分隔」；空文本 / 纯空白 → 无范围（新建流的整文编辑区域不走此表）；CRLF 保真与
  `NoteOps.ToggleTaskAt` 同族规矩。

## 6. 新建流

- ＋ 行与列表空白右键「新建」→ 同一入口 `StartNewNote()`：新 `NoteItem`（Guid、Now 时间戳、
  空文本）插到 `Notes` 头部（显示序天然置顶）→ 展开 + 块编辑（空文本的编辑区域 = 全文）。
- 空稿离场（收起/切卡/面板冲刷）→ 丢弃消失，不留空卡（§4.5）。
- 列表为空时：＋ 行照旧是唯一内容（现状）。

### 8.2 冒烟清单（用户手动，部署后重写）

1. 展开/收起：点卡片就地展开渲染全文；点空白 / ‹ / Esc / Backspace 即回；顺序按最近编辑。
2. 点哪写哪：点段落中间 → 编辑框就地替换该块、光标落到点中的行；其余内容一动不动。
3. 块编辑：打字节流落库；Esc 渲染回去；连点多块连续编辑顺滑；标题/代码块编辑框字号/等宽近似。
4. 接缝排版：块编辑时前后段接缝、编辑框高度变化时下方内容顺滑推移、进出无闪烁。
5. 任务框/链接：渲染态点击回写并保持滚动 / 单次打开；编辑期间前后段不误触。
6. 自动保存：输入后直接隐藏面板 / 退出 → 重开文本完整；收起/切卡/切块不丢字。
7. 空稿：＋ 后不写就切走 / 收起 → 空卡消失。
8. 快速插入：编辑框右键全套菜单（含 Ctrl+Z 单步撤回）。
9. 删除撤回：行菜单删除 + 列表态 Ctrl+Z 多步找回。
10. 三主题 / 三语 / 高对比度下渲染态与编辑框样式正确。
11. 回归抽查：文件夹 / 待办原有行为。
12. 全量自检 `Run-Checks.ps1 -Group all` 32/32。

## 9. 风险与缓解

| 风险 | 缓解 |
|---|---|
| 三段合成处 RichTextBox 自动高度与块间距的接缝 / 闪动 | 间距按渲染器既有 margin 对齐、RTB 零内边距；冒烟重点打磨；offset 捕获/恢复先例 |
| 行级点击命中（内联元素命中链、附加属性挂载） | 显式排除任务框/链接 + 合成事件 pin；命中不到降级块起始行 |
| 滚动 / 焦点在「单 RTB ⇄ 三段合成」切换时丢失 | offset 捕获/恢复；编辑态焦点进编辑框；渲染态焦点回 RTB（Backspace 路由） |
| 编辑中 `Refresh()`（主题/语言/面板刷新）打断编辑 | 护栏：不重建面、不重写编辑框，只重绘 chrome 与前后段；pin 覆盖 |
| 节流窗口内面板隐藏 / 关闭丢最后一批击键 | `Flush()` 挂在离开/收起/隐藏/关闭全部路径；pin 覆盖 |
| 块范围与 CRLF / 空行归属出错 | `NoteBlockRanges` 纯函数逐构造 pin（§8.1） |
| 超长块（大代码块/表格）编辑框高度与性能 | 自动高度、外层滚动承载；冒烟观察 |
| 离屏自检无法验证真实焦点/滚动/排版路径 | 沿用「反射 + 合成事件」pin 口径；焦点/滚动/接缝项冒烟覆盖（T15 先例） |
